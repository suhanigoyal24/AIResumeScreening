Authentication Endpoints

POST /api/auth/register/ Public

Register a new user account. Returns JWT access and refresh tokens.

curl -X POST https://gsuhani17-ats-checker-backend.hf.space/api/auth/register/ \
  -H "Content-Type: application/json" \
  -d '{"username": "hrmanager", "password": "yourpassword", "email": "hr@company.com"}'
POST /api/auth/login/ Public

Login with existing credentials. Returns access token (1 hour) and refresh token (7 days).

curl -X POST https://gsuhani17-ats-checker-backend.hf.space/api/auth/login/ \
  -H "Content-Type: application/json" \
  -d '{"username": "hrmanager", "password": "yourpassword"}'
POST /api/auth/refresh/ Public

Get a new access token using your refresh token.

curl -X POST https://gsuhani17-ats-checker-backend.hf.space/api/auth/refresh/ \
  -H "Content-Type: application/json" \
  -d '{"refresh": "your_refresh_token"}'

Resume Screening Endpoints

POST /api/upload/ Requires JWT

Upload up to 20 resumes (PDF/DOCX) against a job description. Returns ranked scores, matched keywords, and recommendations.

curl -X POST https://gsuhani17-ats-checker-backend.hf.space/api/upload/ \
  -H "Authorization: Bearer your_access_token" \
  -F "resumes=@resume1.pdf" \
  -F "resumes=@resume2.pdf" \
  -F "job_description=We are looking for a Python backend developer..."
GET /api/candidates/ Requires JWT

List all candidates with their scores and extracted skills.

curl https://gsuhani17-ats-checker-backend.hf.space/api/candidates/ \
  -H "Authorization: Bearer your_access_token"
GET /api/dashboard/ Requires JWT

Dashboard summary with pass rates, average scores, and candidate comparison. Filter by minimum score using ?min_score=60.

curl "https://gsuhani17-ats-checker-backend.hf.space/api/dashboard/?min_score=60" \
  -H "Authorization: Bearer your_access_token"
GET /api/dashboard/history/ Requires JWT

Paginated full history of all uploads. Supports ?page=1&search=python&min_score=70.

curl "https://gsuhani17-ats-checker-backend.hf.space/api/dashboard/history/?page=1" \
  -H "Authorization: Bearer your_access_token"
POST /api/ml-analyze/ Requires JWT

Standalone ML analysis for a single resume against a job description.

curl -X POST https://gsuhani17-ats-checker-backend.hf.space/api/ml-analyze/ \
  -H "Authorization: Bearer your_access_token" \
  -F "resume=@resume.pdf" \
  -F "job_description=Looking for a Django developer with REST API experience"

How Scoring Works

Each resume is scored using a weighted blend of four signals:

Final Score = 40% TF-IDF semantic similarity
            + 30% skill overlap (Jaccard index)
            + 20% experience keyword match
            + 10% education keyword match

Scores above 60 → Shortlist
Scores below 60 → Review
